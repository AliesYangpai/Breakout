# 打砖块游戏（Breakout）需求设计文档

- 日期：2026-10-08
- 平台：Android
- 关卡数：10 关，难度逐级提升

## 1. 目标与范围

一款基于 Android 平台的经典打砖块游戏。玩家通过拖动挡板反弹小球，击碎屏幕内所有砖块即可过关。共 10 个关卡，难度逐级提升。

### 核心范围（本期）

- 经典纯玩法：挡板 + 球 + 砖块，无道具掉落。
- 10 个关卡，按"分层递进"组织难度曲线。
- 两种特殊砖块：多击耐久砖、不可破坏砖（硬砖）。
- 固定 3 条命/关，球掉落扣一命。
- 过关目标：击碎全部砖块（不计算硬砖），记录通关 + 剩余命数。
- 顺序解锁关卡 + 关卡选择页 + 本地存档。

### 不在本期范围（YAGNI）

- 道具掉落（加长挡板、多球、慢速球、激光等）。
- 计分、连击、星级评价。
- Boss 砖块。
- 音效/背景音乐、粒子特效、动画过渡的精细化设计。
- 多语言、广告、内购、排行榜。

## 2. 整体架构与模块划分

单屏触控 2D 游戏，按职责划分模块：

| 模块 | 职责 |
|------|------|
| 游戏引擎/循环 | 主循环，固定时间步长更新物理与渲染，负责帧调度 |
| 实体系统 | 挡板、球、砖块的物理状态与碰撞检测（位置、速度、包围盒） |
| 关卡数据 | 10 个关卡的配置（砖块布局、砖块类型、球速、挡板长度），纯数据驱动 |
| 游戏状态机 | 状态流转：菜单 → 关卡选择 → 游戏中 → 暂停 → 过关 → 失败 |
| 进度存档 | 已解锁关卡的本地持久化 |
| UI 层 | 菜单、关卡选择页、HUD（生命/当前关数）、暂停/过关/失败弹窗 |
| 输入处理 | 触摸拖动 → 挡板移动 |

### 关键设计原则

- **关卡数据与逻辑分离**：关卡用可读的数据结构（网格 + 砖块类型）描述，改关卡无需改逻辑代码。
- **固定时间步长**：物理更新用固定步长，避免不同帧率下手感不一致。

## 3. 实体与碰撞

### 三个游戏实体

| 实体 | 关键属性 | 行为 |
|------|---------|------|
| 挡板 Paddle | 位置 x、宽度、速度 | 跟随手指水平移动，左右边界受限；球碰到挡板反弹，反弹角度由击球点离挡板中心的偏移量决定 |
| 球 Ball | 位置、速度向量、当前速度 | 匀速运动，碰墙/挡板/砖反弹；掉落到底部算失一条命 |
| 砖 Brick | 网格位置、类型、耐久值 | 普通砖 1 击摧毁；耐久砖多击摧毁，颜色随剩余耐久变化；硬砖不可摧毁 |

### 碰撞规则

- **球 vs 挡板**：反弹角度按击球点偏移量计算——打在挡板中心垂直上弹，打在边缘为斜角，让玩家能控制球路方向。
- **球 vs 砖**：普通砖→摧毁；耐久砖→耐久 -1，归零才摧毁；硬砖→球反弹、砖不消失。
- **球 vs 左右上墙**：反弹。
- **球掉到底部**：失一条命，球重新从挡板处发射。
- 碰撞检测用 AABB（轴对齐包围盒），球按圆处理。

### 球的"防卡死"规则

- 反弹时若速度方向过于水平，强制加一个最小垂直分量，避免球一直横飞打不到砖。

## 4. 10 关难度曲线（分层递进）

四层结构，每层引入一个新机制，层内逐关加量：

| 层 | 关卡 | 引入机制 | 砖阵密度 | 球速 | 挡板宽度 |
|----|------|---------|---------|------|---------|
| 入门 | 1 | 只有普通砖，教操作 | 少（约 3 排） | 慢 | 宽 |
| | 2 | 普通砖，排数增加 | 中（约 4 排） | 慢 | 宽 |
| | 3 | 普通砖，布局更密 | 中密（约 5 排） | 中慢 | 标准 |
| 耐久层 | 4 | 引入耐久砖（2 击） | 中 | 中 | 标准 |
| | 5 | 耐久砖比例上升 | 中密 | 中 | 标准 |
| | 6 | 耐久砖 + 更高密度 | 密（约 6 排） | 中快 | 标准 |
| 障碍层 | 7 | 引入硬砖（障碍墙），需规划球路 | 中 | 中快 | 窄 |
| | 8 | 硬砖 + 耐久砖混合 | 密 | 中快 | 窄 |
| | 9 | 硬砖数量增多，布局更刁钻 | 密 | 快 | 窄 |
| 终局 | 10 | 混合全部元素 + 高密度 | 最密（约 7-8 排） | 快 | 窄 |

### 难度递增的四个杠杆（逐级收紧）

1. 砖阵排数/密度递增
2. 耐久砖比例递增（第 4 关起）
3. 硬砖障碍占比递增（第 7 关起）
4. 球速递增 + 挡板变窄（全程）

## 5. 游戏状态流转与 UI 流程

### 状态机

```
主菜单 ──▶ 关卡选择页 ──▶ 游戏中 ──▶ 过关 ──▶ 下一关（若 <10）或 通关结算（第10关）
                ▲              │
                │              ├──▶ 暂停 ──▶ 继续 / 重新开始 / 返回关卡选择
                │              │
                └── 失败（命尽）──▶ 重新开始 / 返回关卡选择
```

### 各状态说明

| 状态 | 内容 |
|------|------|
| 主菜单 | 开始按钮 → 进入关卡选择 |
| 关卡选择页 | 10 个关卡卡片（1-10），未解锁置灰锁定，已解锁可进入 |
| 游戏中 HUD | 顶部显示：当前关数、剩余生命（♥♥♥）、暂停按钮 |
| 暂停弹窗 | 继续 / 重新开始 / 返回关卡选择 |
| 过关 | 显示"过关"，按钮进入下一关（第 10 关则显示通关结算） |
| 失败 | 显示"失败"，按钮重新开始 / 返回关卡选择 |

### 生命与球的衔接

每掉一条命，球回到挡板位置，短暂停顿后（或玩家点击）重新发射；3 条命耗尽判失败。

### 关卡解锁逻辑

通过第 N 关 → 解锁第 N+1 关，立即写入本地存档。

## 6. 错误处理与边界情况

| 场景 | 处理 |
|------|------|
| 球无限水平飞行 | 反弹时强制最小垂直速度分量 |
| 球卡在砖/墙之间抖动 | 反弹后加微小位置偏移，防止重复碰撞抖动 |
| 球掉落后重发 | 命 -1，球重置到挡板上方，稍作停顿再发射 |
| 挡板拖出屏幕 | 水平位置钳制在左右边界内 |
| 手指拖动到屏幕外 | 挡板停在边界，不越界 |
| 关卡数据缺失/格式错误 | 回退到该关默认布局（或提示并返回关卡选择） |
| 存档读写失败 | 静默降级为"仅本关可玩"，不崩溃，下次重试写入 |
| App 切后台/锁屏 | 进入游戏自动暂停，回到前台从暂停界面继续 |
| 快速切屏/状态竞态 | 状态机保证一次只在一个状态，非法跳转忽略 |
