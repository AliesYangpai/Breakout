# 打砖块游戏（Breakout）交互设计文档

- 日期：2026-10-08
- 平台：Android
- 依据：`2026-10-08-breakout-game-design.md`

本文档定义游戏从启动到通关全流程的交互行为、手势、视觉反馈与页面跳转。技术实现细节不在本文档范围内。

## 1. 全局交互原则

- **单手竖屏操作**：所有核心操作（拖动挡板、点击发射）均可单手完成，适配主流手机尺寸。
- **立即反馈**：任何可交互元素在触点按下即给出视觉反馈（如挡板高亮、按钮按下态），反馈延迟不超过一帧。
- **不可逆操作需确认**：仅"返回关卡选择"会中断当前局进度，需通过暂停弹窗等二次确认；其他操作可自由进行。
- **防误触**：游戏中屏幕下方为操作区，按钮与挡板操作区之间保留间距，避免误点暂停等按钮。

## 2. 页面与状态流转

```
主菜单 ──▶ 关卡选择页 ──▶ 游戏中 ──▶ 过关 ──▶ 下一关（若 <10）或 通关结算（第10关）
                ▲              │
                │              ├──▶ 暂停 ──▶ 继续 / 重新开始 / 返回关卡选择
                │              │
                └── 失败（命尽）──▶ 重新开始 / 返回关卡选择
```

各页面的交互定义见下节。

## 3. 各页面交互定义

### 3.1 主菜单

- 显示游戏标题与"开始"按钮。
- 点击"开始"→ 进入关卡选择页。

### 3.2 关卡选择页

- 展示 10 个关卡卡片，按 1-10 排列（网格或列表，布局详见视觉稿阶段）。
- **已解锁关卡**：卡片可点击，点击进入对应关卡。
- **未解锁关卡**：置灰 + 锁定图标，点击无响应（或轻提示"先通关上一关"）。
- 当前最新解锁到的关卡：高亮或带"最新"标识，便于玩家定位。
- 返回按钮 → 返回主菜单。

### 3.3 游戏中

**HUD（顶部）：**
- 左侧：当前关数（如"第 3 关"）。
- 中间：剩余生命，用 ♥♥♥ 显示（亮 = 有命，暗 = 已失去）。
- 右侧：暂停按钮。

**挡板操作：**
- 手指按住屏幕任意位置左右拖动，挡板中心水平跟随手指 X 坐标（绝对定位跟随）。
- 挡板水平位置钳制在屏幕左右边界内，手指拖出屏幕挡板停在边界。
- 触点从无到有瞬间，挡板直接跳到手指所在 X（跟随），不做平滑延迟，保证手感直接。

**球的发射：**
- 初始时球吸附在挡板中央上方，随挡板一起水平移动。
- 玩家点击屏幕（非暂停按钮区域）→ 球向上发射。
- 掉命后重新发射：球重新吸附到挡板上方，同样点击发射。
- 发射方向：固定竖直向上，或轻微随机水平偏角（具体角度在实现阶段调参）。

**暂停：**
- 点击 HUD 暂停按钮 → 弹出暂停弹窗（见 3.4）。
- App 切后台/锁屏 → 自动进入暂停弹窗。

### 3.4 暂停弹窗

- 弹窗选项：
  - **继续**：关闭弹窗，恢复游戏。
  - **重新开始**：重开当前关，生命重置为 3。
  - **返回关卡选择**：退出当前局，回到关卡选择页。
- 返回关卡选择为中断性操作，弹窗中单独强调样式；其余操作即时生效。

### 3.5 过关

- 击碎全部可破坏砖后弹出"过关"面板。
- 面板展示：剩余生命（♥ 数量）。
- 按钮：
  - 第 1-9 关："下一关"→ 进入下一关（同时解锁下一关并写入存档）。
  - 第 10 关：显示通关结算（"恭喜通关"），按钮"返回关卡选择"。

### 3.6 失败

- 3 条命耗尽后弹出"失败"面板。
- 按钮：
  - **重新开始**：重开当前关，生命重置为 3。
  - **返回关卡选择**：回到关卡选择页。

## 4. 核心交互细节

### 4.1 球掉落与生命

- 球超出屏幕底部 → 扣一条命（♥ 从亮变暗）。
- 若仍有剩余生命：球吸附回挡板上方，等待点击再次发射。
- 命尽 → 触发失败面板。

### 4.2 碰撞与视觉反馈

| 事件 | 视觉反馈 |
|------|---------|
| 球击中普通砖 | 砖消失 |
| 球击中耐久砖 | 砖颜色变淡/变暗，表示剩余耐久减少 |
| 球击中硬砖 | 球反弹，砖不变（可有轻微闪烁提示"不可破坏"） |
| 球击中挡板 | 球反弹；挡板可短暂高亮 |
| 球击中墙 | 球反弹，无额外反馈 |

### 4.3 触控与按钮的冲突处理

- 游戏中"点击发射"与"暂停按钮"点击需区分：暂停按钮区域内的点击触发暂停，其余区域点击触发发射。
- 挡板拖动（按住移动）与点击发射（单击）通过"是否发生明显位移"区分：位移超过阈值判定为拖动，未超过阈值的抬手判定为点击发射。

### 4.4 状态竞态

- 状态机一次只处于一个状态，非法跳转忽略（如过关面板弹出后，底层游戏输入不再响应）。

## 5. 边界与异常交互

| 场景 | 交互处理 |
|------|---------|
| 球无限水平飞行 | 已由物理规则规避（最小垂直分量），玩家无感 |
| 挡板拖出屏幕 | 挡板停在边界 |
| 快速连点发射 | 球已发射后，点击不再触发二次发射（避免误操作） |
| 过关/失败瞬间用户同时点击暂停 | 状态机忽略，只保留过关/失败面板 |
| 第 10 关通关 | 显示通关结算，不再出现"下一关"按钮 |
| 首次进入（无存档） | 仅第 1 关解锁，其余锁定 |

## 6. 待定项（实现/视觉阶段确定）

- 具体布局尺寸、间距、配色、字体。
- 球的发射偏角、挡板跟随的阻尼/平滑参数。
- 视觉反馈的具体动画（砖销毁动画、球轨迹等）。
- 关卡卡片的具体排列方式（网格或列表）。
