- 关联需求：REQ-01 ~ REQ-18（见 `../1-requirement/requirement-list.md`）

## 1. 页面与状态流转

```
主菜单 ──▶ 关卡选择页 ──▶ 游戏中 ──▶ 过关 ──▶ 下一关（若 <10）或 通关结算（第10关）
                ▲              │
                │              ├──▶ 暂停 ──▶ 继续 / 重新开始 / 返回关卡选择
                │              │
                └── 失败（命尽）──▶ 重新开始 / 返回关卡选择
```

导航实现：`BreakoutApp.kt` 中 `sealed interface Screen`（`Menu` / `LevelSelect` / `Game(levelIndex)`）+ `BackHandler` 驱动；系统返回键按 `Game → LevelSelect → Menu` 逐级返回。

## 2. 各页面交互定义

### 2.1 主菜单（`MenuScreen`）
- 显示标题「打砖块」、副标题「共 10 关 · 难度逐级提升」、按钮「开始游戏」。
- 点击「开始游戏」→ 进入关卡选择页。

### 2.2 关卡选择页（`LevelSelectScreen`）
- 以 5 列网格展示 10 张关卡卡片（`LazyVerticalGrid`，`GridCells.Fixed(5)`）。
- 已解锁卡片：可点击，点击进入对应关卡。
- 未解锁卡片：置灰 + 显示 🔒，`clickable(enabled = false)` 无响应。
- 最新解锁关卡：高亮（`primary` 色），全通关后无高亮标识。
- 「← 返回」按钮 → 返回主菜单。

### 2.3 游戏中（`GameScreen`）

**HUD（顶部）：**
- 左侧「第 N 关」；中间剩余生命用 ♥/♡ 显示；右侧「暂停」按钮。

**挡板操作：**
- 手指按住并左右拖动，挡板中心绝对定位跟随手指 X 坐标（像素 → 逻辑坐标换算）。
- 挡板水平位置钳制在左右边界内，拖出屏幕停在边界。
- READY 状态下挡板移动时球随挡板同步移动（吸附在挡板中央上方）。

**球的发射：**
- 初始球吸附挡板中央上方，随挡板水平移动。
- READY 状态点击屏幕非按钮区 → 球向上发射（初速竖直向上，`velocity = (0, -ballSpeed)`）。
- 掉命后重新回到 READY，球重新吸附，点击再次发射。

**道具掉落物（REQ-13）：**
- 击碎可破坏砖时按配置概率随机掉落道具；硬砖永不触发掉落。
- 掉落物自被击碎砖块中心位置生成，垂直向下匀速运动。
- 掉落物越过挡板下沿（未接住）→ 消失，不生效。
- 挡板接触掉落物 → 拾取，对应道具立即生效。

**四种道具效果（REQ-14/REQ-15，持续到本关结束，不同道具可叠加）：**
- 加长挡板：挡板半宽增大（生效后挡板变宽，边界钳制不变）。
- 多球：场上新增一个球（复制当前球，给予差异化初始角度，避免完全重叠）。
- 慢速球：所有球速度降低（乘以固定系数）。
- 激光：挡板获得激光发射能力（视觉上挡板可辨识，如加高亮边）。
- 效果在本关结束（过关/失败重开/切关）时全部清除，不跨关保留。
- 同种道具重复拾取为幂等（不重复叠加数值，不重复计数）。

**激光发射（REQ-16）：**
- 仅当 RUNNING 状态且持有激光道具时，点击屏幕非空白区 → 从挡板左右两端各发射一束激光（每次点击两束）。
- 两束激光自挡板两端顶面向上飞行，命中砖块造成 1 点伤害（硬砖无伤），激光自身随即消失。
- READY 状态点击仍为发射球（激光不可用）。
- RUNNING 状态无激光道具时，点击非空白区无操作（不发射球）。

**底部空白区移动挡板（REQ-18）：**
- 球运行中，点击挡板下方空白区（逻辑 y > 挡板下沿）→ 挡板中心移动到该点击 x 并边界钳制，不触发发射、不触发激光。
- 该移动与拖动逻辑互不冲突：拖动已由位移阈值区分，单击空白区走移动分支。

**暂停：**
- 点击「暂停」→ 弹出暂停弹窗。
- App 切后台/锁屏（`ON_STOP`）→ 自动暂停并弹出暂停弹窗。

### 2.4 暂停弹窗
- 「继续」：关闭弹窗，恢复游戏。
- 「重新开始」：重开当前关，生命重置为 3。
- 「返回关卡选择」：退出当前局，回到关卡选择页。

### 2.5 过关面板
- 击碎全部可破坏砖后弹出。
- 第 1~9 关：标题「过关！」，按钮「下一关」→ 进入下一关（同时解锁下一关并写入存档）。
- 第 10 关：标题「恭喜通关！」，按钮「返回关卡选择」，无「下一关」按钮。

### 2.6 失败面板
- 3 条命耗尽后弹出「失败」面板。
- 「重新开始」：重开当前关，生命重置为 3；「返回关卡选择」：回到关卡选择页。

## 3. 核心交互细节

### 3.1 球掉落与生命
- 球超出屏幕底部 → 命 -1，状态回 READY，球回挡板上方。
- 命尽 → 状态 LOST，触发失败面板。
- 多球模式下：仅当场上所有球全部掉落才命 -1 并回 READY；仍有一球在场时掉球不扣命。

### 3.2 拖动与点击的区分
- 触点按下后位移超过 8px 判定为拖动（`isDrag`），触发挡板跟随。
- 抬手时若无明显位移，按下列优先级分流单击：
  1. 若点击位于底部空白区（逻辑 y > 挡板下沿）→ 移动挡板（REQ-18）。
  2. 否则若状态为 READY → 发射球（REQ-01）。
  3. 否则若状态为 RUNNING 且持激光 → 发射激光（REQ-16）。
  4. 否则无操作。
- 暂停按钮区域与画布输入区分离，互不干扰。

### 3.3 状态竞态
- 状态机一次仅一状态；`launchBall`/`pause`/`resume` 均做状态守卫，非法跳转忽略。
- 过关/失败面板弹出后，底层游戏循环与输入不再产生新状态迁移。

## 4. 边界与异常交互

| 场景 | 交互处理 | 关联测试用例 |
|------|---------|-------------|
| 球无限水平飞行 | 物理层强制最小垂直分量，玩家无感 | TC-ENT-005 |
| 挡板拖出屏幕 | 挡板停在边界 | TC-ERR-002 |
| 快速连点发射 | 球已发射后点击不二次触发 | TC-GEST-005 |
| 过关/失败瞬间点暂停 | 状态机忽略，只保留过关/失败面板 | TC-STATE-007 |
| 第 10 关通关 | 显示通关结算，无「下一关」按钮 | TC-STATE-004 |
| 首次进入（无存档） | 仅第 1 关解锁 | TC-SAVE-004 |
| 掉落物未接住落出屏幕 | 掉落物消失，不生效 | TC-PROP-003 |
| 多球全部掉落 | 仅当所有球掉落才扣命 | TC-MULTI-002 |
| RUNNING 无激光点击非空白区 | 无操作，不误发球 | TC-LASER-005 |
| 点击底部空白区 | 仅移动挡板，不触发发射/激光 | TC-GEST-007 |
