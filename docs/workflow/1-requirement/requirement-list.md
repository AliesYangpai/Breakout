# 打砖块游戏（Breakout）需求清单

- 迭代版本：V1.1.0.20261011
- 文档创建人：Alie
- 创建时间：2026-10-09
- 关联需求：REQ-01 ~ REQ-18（本清单即需求源）

## 1. 需求背景

一款 Android 平台经典打砖块游戏。玩家通过拖动挡板反弹小球，击碎屏幕内所有砖块即可过关。共 10 个关卡，难度逐级提升，采用竖屏单手操作。

## 3. 不在本期范围（YAGNI，显式排除）

- 计分、连击、星级评价、Boss 砖块。
- 音效/背景音乐、粒子特效、动画过渡精细化。
- 多语言、广告、内购、排行榜。
- 跨平台（Flutter/React Native）、游戏引擎、第三方物理引擎、SQLite/Room。

> 反向验证用例见测试用例文档 `TC-FUNC-007`。
