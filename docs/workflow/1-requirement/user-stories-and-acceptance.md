# 打砖块游戏（Breakout）用户故事与验收标准

- 迭代版本：V1.0.0.20261010
- 文档创建人：Alie
- 创建时间：2026-10-09
- 关联需求：REQ-01 ~ REQ-12（见 `requirement-list.md`）

## 1. 用户故事

### US-01 开始一局游戏
作为玩家，我想从主菜单进入关卡选择页，点选已解锁关卡开始游戏，以便随时进入想玩的关卡。

- 关联需求：REQ-01、REQ-06、REQ-07
- 验收标准：AC-07、AC-06

### US-02 拖动挡板接球
作为玩家，我想通过手指左右拖动挡板接住小球，让球反弹击碎砖块，以便通关。

- 关联需求：REQ-01、REQ-08、REQ-10
- 验收标准：AC-01、AC-08、AC-10

### US-03 击碎砖块并识别特殊砖
作为玩家，我想区分普通砖、耐久砖、硬砖的击打反馈，以便规划球路高效通关。

- 关联需求：REQ-01、REQ-03、REQ-05、REQ-09
- 验收标准：AC-01、AC-03、AC-05、AC-09

### US-04 理解生命机制
作为玩家，我想知道剩余生命数，并在球掉落时看到生命减少、重新发射，以便控制容错。

- 关联需求：REQ-04、REQ-07、REQ-10
- 验收标准：AC-04、AC-07、AC-10

### US-05 过关与失败
作为玩家，我想在通关后进入下一关（或看到通关结算），失败后重新开始或返回选关，以便持续推进。

- 关联需求：REQ-01、REQ-05、REQ-07
- 验收标准：AC-01、AC-05、AC-07

### US-06 进度持久化
作为玩家，我想在通关后解锁下一关，并在下次启动时保留解锁进度，以便不必重复通关。

- 关联需求：REQ-06
- 验收标准：AC-06

### US-07 暂停与切后台保护
作为玩家，我想在暂停、切后台、锁屏时游戏自动暂停，以便避免误损失生命。

- 关联需求：REQ-07、REQ-11
- 验收标准：AC-07、AC-11

### US-08 防卡死与稳定运行
作为玩家，我希望球不会无限水平横飞或卡在砖墙间抖动，任何快速操作都不会导致崩溃或状态错乱，以便获得稳定体验。

- 关联需求：REQ-09、REQ-12
- 验收标准：AC-09、AC-12

### US-09 难度逐级提升
作为玩家，我希望从第 1 关到第 10 关难度逐步增加（砖更多、耐久/硬砖更多、球更快、挡板更窄），以便获得有挑战的成长曲线。

- 关联需求：REQ-02
- 验收标准：AC-02

### US-10 顺序解锁
作为玩家，我希望只能进入已解锁的关卡，未解锁关卡置灰锁定，以便形成通关激励。

- 关联需求：REQ-06、REQ-07
- 验收标准：AC-06、AC-07

## 2. 验收标准

| 验收标准 ID | 验收标准描述（可验证） | 关联需求 | 关联测试用例 |
|------------|----------------------|---------|-------------|
| AC-01 | 球在挡板/墙/砖之间反弹，砖被击碎后消失，全程可玩无卡死 | REQ-01 | TC-FUNC-001 |
| AC-02 | 共 10 关（索引 0~9）；球速非递减、挡板宽度非递增、硬砖仅第 7 关起、每关至少一个可破坏砖 | REQ-02 | TC-FUNC-002、TC-DIFF-001~005 |
| AC-03 | 普通砖 1 击摧毁；耐久砖按类型 2/3 击摧毁；硬砖永不摧毁 | REQ-03 | TC-FUNC-003/004/005 |
| AC-04 | 固定 3 条命/关；球越过底部后命 -1、状态回 READY、球回挡板；命尽状态 LOST | REQ-04 | TC-ENT-004、TC-STATE-006 |
| AC-05 | 场中无可破坏砖时判定 WON；存在硬砖 + 可破坏砖时不为 WON | REQ-05 | TC-FUNC-006 |
| AC-06 | 通关第 N 关解锁第 N+1 关并写入存档；解锁单调不回退；首次进入仅第 1 关解锁 | REQ-06 | TC-SAVE-001~004 |
| AC-07 | 菜单/关卡选择/HUD/暂停/过关/失败页面按交互文档流转且文案正确 | REQ-07 | TC-UI-001~008、TC-STATE-001~006 |
| AC-08 | 挡板绝对定位跟随手指并边界钳制；READY 状态点击发射、RUNNING 状态点击不二次发射；拖动与点击按位移阈值区分 | REQ-08 | TC-GEST-001~006、TC-ENT-001 |
| AC-09 | 反弹后始终保留足够垂直速度分量，球不会水平横飞；命中后稳定弹出，无高频抖动/卡墙 | REQ-09 | TC-ENT-005/006 |
| AC-10 | 挡板拖出屏幕停在边界；掉命后重新吸附发射；存档异常时不崩溃静默降级 | REQ-10 | TC-ERR-002/003/004 |
| AC-11 | 游戏中切后台/锁屏后回前台自动弹出暂停弹窗，球停止移动 | REQ-11 | TC-ERR-005 |
| AC-12 | 过关/失败面板弹出后底层输入不再响应，快速操作不崩溃，状态始终唯一 | REQ-12 | TC-STATE-007、TC-ERR-006 |
