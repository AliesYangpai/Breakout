# Skill：04-开发编码阶段

## 触发指令
`/skill 04-code`

## 目标
基于技术设计文档，完成代码开发、单元自测，保证代码符合规范。

## 执行步骤
1. 按模块拆分任务，编写业务代码。
2. 编写单元测试，关键逻辑增加注释。
3. 本地自测，验证功能符合交互文档与需求验收标准。
4. 代码规范检查，处理编译警告。
5. 提交代码，提交前进行本地验证（Android：编译debug包，基础功能验证）。
6. 输出开发自测记录。

## 交付物（输出到 docs/workflow/4-code/）
- 开发自测记录

## 退出条件
开发自测完成，代码提交，进入【测试回归阶段】。
