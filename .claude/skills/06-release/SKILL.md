# Skill：06-版本发布阶段

## 触发指令
`/skill 06-release`

## 目标
完成版本打包、发布检查、版本归档，完成本次迭代闭环。

## 执行步骤
1. 核对代码分支，确认待发布代码基线。
2. 版本打包（Android：构建Release包，核对版本号）。
3. 发布检查清单校验：权限、配置、版本号、隐私文案、资源完整性。
4. 编写更新日志（changelog），记录新增功能、修复bug。
5. 版本归档，记录发布信息。
6. 迭代复盘：本次迭代问题、经验，记录到文档。

## 交付物（输出到 docs/workflow/6-release/）
- 版本更新日志 changelog
- 发布检查清单
- 版本归档记录
- 迭代复盘文档

## 退出条件
版本发布完成，本次迭代闭环。如需新增功能或后续bug，再次从【01-需求阶段】启动。
