# Skill：02-交互与测试用例阶段

## 触发指令
`/skill 02-interaction`

## 目标
基于已锁定需求，完成产品交互逻辑梳理，**同步编写测试用例**（重点：测试用例在交互阶段产出，不等编码完成）

## 执行步骤
1. 根据需求验收标准，梳理页面/模块完整交互流程，包含主流程、分支流程、异常场景。
2. 输出交互说明：页面跳转、状态变化、弹窗、加载、报错提示。
3. 编写全套测试用例：正常场景、边界场景、异常场景；每条用例绑定需求验收点。
4. 评审：交互逻辑 + 测试用例覆盖度，确认是否覆盖全部需求。
5. 文档归档。

## 交付物（输出到 docs/workflow/2-interaction/）
- 交互逻辑说明文档
- 完整测试用例文档

## 退出条件
交互文档、测试用例评审通过，进入【开发设计阶段】。
