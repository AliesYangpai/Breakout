# Skill：05-测试回归阶段

## 触发指令
`/skill 05-test`

## 目标
使用交互阶段产出的测试用例，执行功能测试、回归测试，发现bug并闭环。

## 执行步骤
1. 基于前期产出的测试用例执行测试。
2. 记录bug：现象、复现步骤、预期结果、实际结果、严重等级。
3. 提交bug，分配给开发修复。
4. 开发修复完成后，执行回归验证。
5. 全部bug闭环后，整理测试报告。
6. 若存在严重bug / 需求变更，触发回流：回到【01-需求阶段】评估。

## 交付物（输出到 docs/workflow/5-test/）
- bug清单
- 回归测试报告

## 退出条件
所有阻断性bug修复、回归验证通过，进入【版本发布阶段】。
